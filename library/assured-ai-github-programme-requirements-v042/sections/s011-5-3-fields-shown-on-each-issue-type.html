5.3 Fields shown on each issue type

Organisation issue fields must be pinned to issue types to appear on the issue form. GitHub allows up to 10 pinned fields per issue type. Pin only these. Fields not pinned to a type can still be set from the project views.

Issue typePinned fields
EpicWorkstream, Programme status, Delivery health, Pipeline stage, Integration readiness, Gates output, Primary research question, Start date, Target date, Backlog ref
MilestoneProgramme status, Delivery health, Gates output, Start date, Target date
Research questionProgramme status, Primary research question
DependencyWorkstream, Programme status, Delivery health, Risk category, Impact, Target date
DecisionWorkstream, Programme status, Target date
AssumptionWorkstream, Delivery health, Impact, Target date
Feature, Story, SpikeWorkstream, Pipeline stage, Integration readiness, Delivery health, Risk category, Impact, Review type, Review status, Primary research question, Target date
