15. Acceptance criteria

IDCriterion
AC-01The programme project and the template exist in the agreed organisation, with the agreed access for partners, Gates Foundation contacts and WHO staff
AC-02Every view in section 8.1 exists and shows the intended items
AC-03The section 7.1 fields are organisation issue fields, and no project field duplicates them (unless the section 7.4 fallback was used)
AC-04Every epic from the CSV appears once in V1
AC-05Every Gates output has exactly one milestone issue and one saved filter in V3
AC-06All seven research questions exist, and every epic has a Primary research question, which may be None
AC-07Every D-number from the register exists once in aai-programme and links to the waiting epic and what it waits on; native "blocked by" relationships exist only where DEP-03 calls for them
AC-08No restricted material (section 6) appears in any shared repository
AC-09No automation sets readiness, approval, risk category, impact, a decision or risk acceptance
AC-10The READMEs explain each field, how items enter the project, who owns what, what is restricted and why, and how the projects link
AC-11All pilot tests PIL-01 to PIL-11 passed before the bulk import
AC-12No aai-ws5 repository or WS5 project exists. Every workstream repository created so far exists in the WHO organisation with the agreed roles, and none was created before its lead was confirmed; no issue from an external repository has been added to the programme project
AC-13WS5 Governance and stewardship is not represented as the final sequential pipeline stage; cross-cutting items use Pipeline stage = Cross-cutting / N/A where appropriate
AC-14Every D-number and DEC-number issue title starts with its number
AC-15Organisation issue-field headroom and every project's total field count are within GitHub limits, and both are recorded in the build report
AC-16Every item with a Gates output value also carries the matching gates: label
AC-17Every item with a Primary research question other than None also carries the matching rq: label
AC-18Charts M1 to M5 exist, or the report records which cannot be built natively
AC-19Every pilot item in V10 carries a "Next action" line in its issue body
